# Yummy Points

## Vision

Turn missed treats into future treats.

## Core Concept

When a child misses out on a treat or experience, parents award points.
Children can later redeem those points for rewards.

## MVP

- Authentication
- Families
- Children
- Points
- Rewards
- Journey

## Decisions

- Multiple children supported
- Parent-defined points economy
- Shared reward templates
- Parent-first experience
- Hidden badges
- Customisable point name
- No photos in v1
- No streaks
- No leaderboards
- No notifications
- No allergy management features

## Tech Stack

- React
- TypeScript
- TanStack Router
- Supabase
- GitHub
- Lovable (hosting/preview only)
